# Dossier projet

Ce dossier regroupe les livrables professionnels du projet AI Dataset Studio.

## Organisation

- `01_Project_Charter/` : charte et vision projet.
- `02_Requirements/` : cahiers des charges fonctionnel et technique.
- `03_Architecture/` : architecture, diagrammes, flux de données.
- `04_Design/` : maquettes UX/UI.
- `05_Meeting_Reports/` : comptes rendus de réunion.
- `06_Daily_Reports/` : journal de bord.
- `07_Testing/` : stratégie et rapports de tests.
- `08_Documentation/` : guides technique et utilisateur.
- `Presentation/` : support de soutenance ou démonstration.
