# AI Dataset Studio - Project Charter

## Vision

Créer une plateforme web intuitive, de type Canva des datasets IA, permettant d'importer, nettoyer, annoter, contrôler, équilibrer et exporter des datasets prêts à l'entraînement.

## Objectifs

- Démocratiser la préparation de données pour l'IA.
- Réduire le temps de nettoyage et d'annotation.
- Rendre les transformations traçables et reproductibles.
- Exporter vers les formats standards de l'écosystème IA.

## Périmètre MVP

Inclus : import CSV/JSON, profiling qualité, nettoyage de base, annotation simple, export CSV/JSON, journal des transformations.

Hors périmètre initial : entraînement complet de modèles, connecteurs cloud complexes, annotation vidéo avancée, facturation ou multi-tenant entreprise.

## Cibles

- Chercheurs : rigueur, traçabilité, compatibilité académique.
- Startups IA : rapidité, coûts maîtrisés, intégration pipeline.
- Universités : outil pédagogique simple.

## Jalons

- M1 : Conception validée.
- M2 : Import et nettoyage opérationnels.
- M3 : Annotation et contrôle qualité.
- M4 : Export et documentation.
- M5 : Livraison MVP.
