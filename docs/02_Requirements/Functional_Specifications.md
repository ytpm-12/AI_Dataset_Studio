# Cahier des charges fonctionnel

## Parcours cible

1. Créer un projet dataset.
2. Importer un fichier CSV ou JSON.
3. Visualiser le dataset et ses métriques qualité.
4. Appliquer des règles de nettoyage avec prévisualisation.
5. Annoter et valider les données.
6. Exporter le dataset préparé.
