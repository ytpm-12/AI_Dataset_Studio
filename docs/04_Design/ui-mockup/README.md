# AI Dataset Studio - UI mockup

Maquette HTML, CSS et JavaScript autonome pour explorer les pages principales de AI Dataset Studio.

Ouvrir `index.html` dans un navigateur, puis utiliser la navigation laterale.

Écrans inclus:

- Tableau de bord
- Projets
- Version active
- Import
- Analyse et profilage
- Nettoyage
- Documents PDF
- Images
- Annotation
- Recommandations IA
- Équilibrage
- Rapport qualité
- Export
- Traitements
